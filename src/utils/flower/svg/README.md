# SVG 花材试验

玫瑰、郁金香、小雏菊各使用独立的花头和无叶花茎 SVG；其他花材沿用原造型。

- 花头坐标为 110 × 110，中心 (55, 55)，`__COLOR__` 在加载时替换为花色。
- 花茎坐标为 110 × 260，从 (55, 55) 延伸到瓶口 (55, 260)。
- 花头单独缩放，花茎沿 Y 方向伸缩，整枝共用瓶口旋转点。
- 通过 Vite `?raw` 读取 SVG，转换为 Base64 后交给 `<image>`，无需网络服务或额外依赖。
- 本轮是 Base64 SVG 加载试验。uni-app 文档注明小程序 SVG 只支持网络地址，不能据此保证微信真机支持此方案；`image` 触发错误时会回退到原 CSS 花头 / PNG 花茎。
- 图片导出仍使用原 Canvas 近似造型，暂未同步新 SVG。JSON 保存格式不变。

## 手动验证

1. 打开花草工作室：默认展示小雏菊、玫瑰、郁金香；玫瑰应有锯齿叶，郁金香应有长叶。
2. 点击花头切换颜色，确认花瓣换色，茎叶保持绿色。
3. 拖动调整高度和角度，确认花头与花茎连接、底端固定在瓶口。
4. 复制花材并调整前后层，再撤销，确认 SVG 仍跟随作品数据。
5. 分别在 H5、微信开发者工具和微信真机检查；出现原造型表示 SVG 加载失败并已回退。
