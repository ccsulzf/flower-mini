# 每日插花维护

这个分包只在开发环境注册，不会进入正式小程序包。首页的「每日插花维护」入口也仅在开发环境显示。

## 本地 JSON 格式

将草稿 JSON 粘贴到管理页。每枝花材和花器必须包含已存在于云端的素材 ID；如指定背景素材，也必须存在于云端。预览时会校验并加载这些素材。

## 发布流程

1. 登录有 `admin` 角色的账号。
2. 在首页开发入口打开维护页面，粘贴准备好的 JSON 并点击预览。
3. 预览花束、日期和描述。
4. 确认发布后，云端渲染器将 698 × 1000 SVG 画布直接栅格化为 1396 × 2000 PNG；图片上传后，云对象验证图片和花束数据并写入 `daily-flower` 集合。
5. 同一日期再次发布会覆盖文档并删除旧图片；如果云存储清理失败，页面会显示警告。

新增云对象 `flower-daily-admin`、更新 `flower-render` 的管理端渲染方法，并部署 `uniCloud-alipay/database/daily-flower.schema.json` 后，管理端才能完成云端发布。
