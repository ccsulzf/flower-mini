# 花瓶小作：微信小程序测试用例

更新日期：2026-11-18。依据当前工作区代码整理；全部用例状态为「未执行」，预期结果是验收目标，不代表已验证。

## 范围与执行约定

- 客户端为微信小程序（MP-WEIXIN），后端为支付宝 uniCloud；本清单不要求测试支付宝小程序。
- 默认首屏是插花创作台，pages/index/index-page 是辅助入口。管理分包按实际编译开关与账号权限测试。
- P0：核心链路、数据安全与数据保留；P1：边界、恢复、兼容与体验。建议先执行 P0。
- 使用隔离测试云空间、两个微信测试账号 A/B、专用可删除作品；破坏性与异常注入仅用于测试数据。
- 准备：无作品账号、超过一页作品账号、多种花器和花材、多个日期每日花束、可控云调用失败与慢网场景。
- 开发者工具用于启动参数、基础库切换、调试及可控异常；涉及微信登录身份、触摸、分享、权限、键盘和性能的结果以真机为准。
- 至少覆盖 iOS/Android 微信真机、小屏/全面屏、团队支持的最低与当前基础库；执行时记录系统、微信、基础库、构建版本、云空间与网络。最低支持版本未从本项目中确定，应执行前补齐。
- 无法注入异常或当前版本无对应入口时，记「阻塞」或「不适用」并写明原因，不能记通过。
- 字符边界先用 ASCII 精确构造；另外测试中文、表情和换行。代码使用 JavaScript length 时不应把表情个数直接等同长度。

## 上线前执行顺序

- 先确认体验版客户端与云对象部署版本、模型配置、素材目录及每日限额模式；当前工作区限额开关为无限制调试模式，不能按每日三次已生效验收。
- 优先执行全部 P0，重点串联 WX-001 → WX-075 → WX-076 → WX-085 → WX-026 → WX-035 → WX-049 → WX-056，并执行 WX-059、WX-067、WX-068、WX-071、WX-100。
- 异常注入、账号隔离、并发与限额用例仅在隔离测试云空间执行；不能注入时标记阻塞，不能当成通过。上线前逐项补齐实际结果及缺陷记录。
