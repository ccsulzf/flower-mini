# 鲜花创作界面一致性设计规格

## 目标

以 `pages/flower-studio/flower-studio-page` 作为用户首页和视觉基准，统一创作、完成、详情、贺卡与作品列表的颜色、文字、按钮、卡片、弹层和状态反馈。保留现有数据模型、云对象调用和页面导航逻辑。

成功标准：用户从插花到保存、查看、继续编辑和制作贺卡时，能够识别一致的主要操作、次要操作和危险操作；面板打开后仍能判断画面变化；不同页面看起来属于同一款产品。

## 设计方向

采用“自然纸张”方向：暖米白作为页面底色，暖白作为内容表面，鼠尾草绿作为品牌与主要交互色，炭灰绿作为正文色。颜色保持低饱和，不使用当前演示页的蓝灰渐变。

备选方向未采用：

- 保留各页面局部样式，仅修正明显冲突。改动较少，但会继续累积重复色值和交互差异。
- 引入全新的高对比品牌色和组件库。视觉变化更强，但会扩大范围并增加小程序兼容风险。

## 全局视觉规则

在现有 SCSS token 中建立鲜花主题，页面和组件优先使用 token，不再新增重复硬编码颜色。

- 页面背景：`#f6f3eb`
- 主要表面：`#fffdf7`
- 次级表面：`#f0efe6`
- 主文字：`#3f463d`
- 次文字：`#737b6c`
- 品牌色：`#74806b`
- 品牌浅色：`#dfe6d7`
- 边框：`#dde1d4`
- 危险色：`#a85f62`
- 圆角：小型控件 16rpx，按钮与卡片 20–28rpx，弹层 30rpx
- 阴影只用于浮层和可点击卡片，页面内容避免漂浮感

文字层级统一为页面标题、区块标题、正文、辅助说明和标签五档。按钮点击区域最低 72rpx；禁用状态使用降低对比度和透明度，不改变布局。

## 交互层级

按钮分为四类：

1. 主要操作：实心鼠尾草绿或浅绿色按钮，每个操作区只出现一个。
2. 次要操作：暖白表面、细边框，用于保存图片、复制和返回等动作。
3. 轻量操作：无底色文字或图标，用于编辑标题、关闭面板等动作。
4. 危险操作：低饱和红色文字，只在明确位置出现；删除继续使用确认弹窗。

加载、成功、警告和错误反馈使用同一套全局 toast 视觉。异步按钮在原位置显示进行中状态并禁用，避免页面跳动。

## 页面设计

### 插花工作台

- 保持其为应用首页，不增加介绍型首页。
- 保留顶部撤销、重做、清空和完成，统一按钮高度、禁用态和按压态。
- 空白作品不应出现可用的撤销按钮；默认花器初始化不得进入用户撤销历史。
- 花材、容器和背景面板采用一致的底部工作面板，标题、关闭按钮、分类标签和卡片状态共用样式。
- 面板打开时缩放或抬高画布，使花器和主要构图区域仍然可见。
- 添加花材后，素材卡片短暂显示已添加状态，画布中的新增花材保持选中，撤销按钮同步启用。
- “我的作品”保持顶部入口，但使用与全局次要按钮一致的样式。

### 完成页

- 作品保持视觉中心，说明文字缩短并靠近操作区。
- 主要保存按钮固定在底部安全区上方，状态包括默认、保存中、失败重试。
- 编辑已有作品时使用“保存修改”；新作品使用“保存作品”，文案与详情页保持一致。

### 作品详情

- 顶部只保留分享和保存图片两个轻量操作。
- 底部将“继续编辑”设为主要按钮，“制作贺卡”设为次要按钮。
- 标题、描述与日期组成紧凑的信息区，标题编辑入口保持可发现。
- 加载中保留画面骨架和固定操作区，避免按钮在完成加载后突然换位。

### 制作贺卡

- 预览保持主体，底部操作使用与详情页相同的按钮层级。
- “填写内容”为主要操作；“保存图片”和“分享贺卡”为次要操作。
- 编辑表单使用统一底部弹层；标签、输入框、字数统计、关闭按钮和完成按钮遵循全局规范。
- 更新预览时仅覆盖预览区域，不禁用无关导航。

### 我的作品

- 单列通栏卡片展示作品缩略图、完整标题、更新时间和主要入口，减少大面积空白。
- 点击卡片进入详情；复制作为次要操作。
- 删除收进轻量操作区并使用危险色，继续保留二次确认。
- 空状态提供一条明确的“去插花”主要操作。

### 演示页面

`pages/index/index-page` 不属于消费端主路径。本次仅让它继承新的公共背景与 token，不扩展其信息架构，也不将其入口加入工作台。

## 代码结构

- `src/styles/variables.scss`：提供全局主题 token 与通用 mixin。
- `src/styles/flower-studio.scss`：从全局 token 派生工作台变量，避免形成第二套主题。
- 全局样式文件：维护页面、按钮、卡片、状态标签和底部安全区的可复用类。
- 页面文件只保留布局特有样式；页面中已有的重复色值迁移到 token。
- 不引入新依赖，不修改 `node_modules` 和生成声明文件。

## 错误与边界状态

- 素材加载失败、账号连接失败、作品加载失败和图片生成失败均保留当前重试路径，并统一错误视觉。
- 网络回退到云函数属于开发环境行为，不在本次 UI 修改中改变。
- 分享菜单、相册权限和真机 Canvas 仍需微信开发者工具及真机验证。
- 小屏设备上底部操作区不得遮挡作品或表单，所有页面考虑 `env(safe-area-inset-bottom)`。

## 验证

- 运行已有离线测试：`node --test tests/*.test.cjs`。
- 使用微信开发者工具体验：空白工作台、素材面板、撤销、完成保存、详情、贺卡和作品列表。
- 对 iPhone 12/13 模拟尺寸进行截图检查，确认画布、底部操作区和弹层无重叠。
- `pnpm type-check`、`pnpm lint` 和小程序构建仅在获得当前会话明确授权后运行。

## 不在本次范围

- 修改云端数据结构或鉴权流程。
- 重做花材插画、渲染引擎或拖拽算法。
- 发布、上传小程序或执行真机分享。
- 将开发工具页面改造成新的用户首页。
