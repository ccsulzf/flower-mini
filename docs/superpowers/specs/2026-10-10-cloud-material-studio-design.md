# 云端素材进入工作台与花瓶素材管理

## 目标

使用已经上传的花材走通：管理页上传 → 云端目录 → 微信本地文件缓存 → 工作台选材 → 插花 → 完成图片。花瓶同样由本地档案预览、上传、下载并在工作台选择。运行与发行包都能消费云端素材；本地待审核档案和管理分包只进入开发包。

## 现状

花材档案存于 flower-material-assets。工作台仍用固定六种花材与 CSS 花瓶，flower-catalog 查询旧 flower-materials 集合。完成图片由 Canvas 近似绘制，不能直接保证新素材出现在图片中。现有一份已上传素材需先读取真实记录，确认文件字段、版本与 SVG 坐标，不假定是哪一种。

## 档案模型

将正式运行需要的类型移到 src/models；管理页仍独立。

- category：flower 或 vase，旧记录缺失时解释为 flower。
- 公共字段：id、name、introduction、version、revision、assets、服务端时间。
- 花材：flowerMeaning、group（main/filler/foliage）、colors；flower、stemWithLeaves、stemWithoutLeaves 或 foliage 四类文件；增加渲染尺寸与连接点说明。
- 花瓶：vase.svg；以 viewBox 为坐标系记录显示尺寸、瓶口中心、瓶口可插范围。无需花语或花色字段。
- 已上传三种示例花材可按已知 ID 补默认连接几何；任意新品种必须明确几何，缺少时提示补齐，不用玫瑰造型替代。
- 素材比较 revision 同时包含 metadata 与文件内容；新增类别和几何参与比较。

管理页增加“花瓶”分类。花瓶独立目录包含 material.json 与 vase.svg，详细卡片展示介绍和花瓶预览。先提供一份陶瓶示例供真实上传验证。保留已上传花材，兼容旧档案，不清空数据或覆盖原 SVG。

## 云端接口

flower-material-admin 继续使用已校验 Token 的 uid 查询实时 admin 角色，读取与写入使用同一 flower-material-assets 集合。严格区分花材和花瓶输入，写入身份取服务端，schema 同步更新。

flower-catalog 从档案集合提供可用花材与花瓶及版本、几何、文件 ID、下载地址。不再依赖旧 catalog.json；普通登录用户只读，通过云对象访问。分页完整返回目录，避免超过100条时错误判定状态。失效 Token 的续期遵循 uniCloud 标准返回机制。

## 客户端缓存与状态

登录就绪后调用目录云对象。每个文件先查持久缓存，按内容 hash 校验；缺失或损坏才下载，校验后保存到微信持久文件目录。相同内容不因临时 URL 改变而重复下载。

Pinia 共享 store 管理目录、加载、错误、缓存结果与按 ID 查找。相同加载任务合并；明确显示读取、下载、就绪、失败和重试。失败不能把本地内置素材标作云素材或假装成功。已有旧作品可以继续使用原本地素材，新云素材必须缓存成功才允许添加。

首轮验证记录目录数量、实际下载数量与缓存命中，二次进入或重启后验证持久缓存。

## 工作台与作品

选材面板显示云端花材与花瓶。花枝增加 materialId、素材 revision 和带叶/去叶选择；作品增加 vaseMaterialId 与 revision。保留原 kind/vase 字段兼容现有默认作品和 JSON 预览，但云素材渲染必须依据真实素材 ID。

花朵、茎叶和叶材使用缓存的 SVG，按照素材几何放置；颜色只替换约定占位。花瓶按照自己的瓶口几何定位，切换花瓶时约束花枝底端，不改变角度、高度等用户已做的编辑。撤销、重做、复制、删除保留新字段和素材引用。

不自动把新上传档案加入当前作品。用户主动从云目录选择后才添加。花瓶也需从列表主动选择。

## 图片生成

完成图片不能再用本地近似造型替换云端素材。让导出使用相同缓存素材和几何进行绘制，验证微信 Canvas 是否支持当前 SVG 文件；若原生不支持，补实现本地 SVG 栅格化或同版本 PNG 衍生素材后再视为流程完成。加载/转换失败明确报错，不导出错误花朵的图片。

## 验证与交付

1. 离线：旧档案兼容、花瓶字段验证、身份和目录接口、缓存持久化/损坏重下、作品历史/几何与素材引用、导出素材加载失败。
2. 相关 TypeScript、Vue 脚本与模板只读检查。
3. 实际服务空间：读取用户已上传的一份素材，首次下载、工作台添加、调整、完成图；再加载命中缓存。陶瓶示例上传后重复验证。
4. 正式包确认不含管理页面和待审核文件，但包含消费云素材的组件与缓存工具。

未经授权不运行包管理器构建/安装；真实运行优先使用已有 HBuilderX/微信工具。若工具不可访问或缺少服务端权限，明确列出未验证步骤，不将离线测试等同于完成真实联调。

## 范围之外

本次不做批量删除、云端文件垃圾回收、商城、花店业务或素材搜索。旧未关联文件不自动删除。已有登录配置、密钥、生成声明和第三方模块不手改。
