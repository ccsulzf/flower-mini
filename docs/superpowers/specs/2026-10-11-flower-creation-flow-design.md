# 按流程图实现完整插花与花卡流程

## 依据与范围

以用户本次提供的流程图为准，替代之前“完成后仅展示保存/分享图片浮层”的流程。保留现有花材、容器、背景、拖动、镜像、颜色、层级、复制、删除及撤销重做；将本地恢复、作品预览、花卡编辑、花卡预览、结束创作接入同一会话。

这次属于架构改动：调整启动入口、跨视图状态、本地缓存生命周期和两种图片导出。实现不增加依赖，不安装或修复依赖，不上传素材、不部署云端、不修改生成声明或第三方模块。保留 default layout 的 Feedback 全局挂载。

## 启动与恢复

- 小程序启动直接进入全屏插花页面。现有首页不再作为启动页，仍保留为辅助页面；素材管理仍只包含在开发包中。
- 立即展示空默认花瓶，不等登录、目录或素材下载才展示画布。鉴权素材读取继续等待 waitForAppAuthReady。
- 登录初始化完成后检查有效本地创作缓存；等待恢复选择期间不写入初始空作品，不用默认花瓶替换已恢复容器。
- 无缓存：进入空花瓶的全屏插花页。
- 有缓存：显示恢复提示浮层，两个动作是“继续上次创作”和“重新开始”。继续恢复花材、容器、背景、每个容器布局及已提交的花卡文字；重新开始清除本次创作缓存并回到空默认花瓶。
- 缓存损坏/版本不支持：提示无法恢复并进入空创作；不删除素材文件缓存。
- 恢复提示每次新页面会话只显示一次；从预览或系统相册/分享返回不重复弹出。

## 全屏插花与工具浮层

采用自定义导航和安全区布局，兼顾微信胶囊、状态栏及底部安全区。插花工具与预览分别作为同一页面内的独立视图，避免跳转导致编辑状态丢失。

- 选花、换花器、换背景打开工具浮层；选花后浮层保持打开；容器和背景遵循现有明确选择行为。
- 点击花材打开单枝工具，继续提供镜像、颜色、前后层、复制、删除和上一枝/下一枝。
- 收起工具回到全屏插花页，保留作品。
- “清空花材”仍只移除花材，支持撤销；与“结束本次创作”清缓存严格区分。
- “完成”进入作品预览，不清除缓存。
- 容器加载失败可重试；已有作品和背景保留。

## 作品预览页

用完整页面视图展示原作品图片，不包含编辑工具、选中圈或花卡文字。进入时自动生成，生成中禁用保存/分享，失败显示重试。

动作与流向：

1. “返回编辑” → 全屏插花页，恢复同一作品与容器布局。
2. “保存图片” → 手机相册，留在作品预览。
3. “分享” → 花卡编辑浮层。
4. “结束本次创作” → 清除创作缓存、花卡文字与本次编辑历史 → 空默认花瓶的全屏插花页。

完成、保存、分享、取消均不自动清缓存。只有恢复提示里的“重新开始”和预览里的“结束本次创作”清除创作缓存。

## 花卡编辑浮层

在作品预览上打开浮层，填写两个可选字段：祝福（多行，最多 120 字）和署名（最多 24 字）。字段均使用大陆常用中文提示。输入使用临时副本，避免取消后改写已提交花卡。

- “取消” → 作品预览，丢弃本次未提交修改，保留上一次已提交的花卡文字。
- “跳过” → 分享原作品图，返回后仍在作品预览。
- 点击“预览花卡”：祝福和署名去除首尾空白后全部为空，则直接分享原作品图；任一非空则提交文字并进入花卡预览。
- 从花卡预览的“修改祝福或署名”进入时带回已提交文字；取消按流程图返回作品预览。

所有花卡编辑取消分支均按图返回作品预览；再次打开编辑时仍可使用上次已提交的文字。

## 花卡预览

花卡在同一页面内使用独立完整预览视图。图片为原作品加底部浅色文字区域；作品保持比例，文字自然换行，署名靠右。单独限制祝福和署名长度，不挤压花朵，不截断文字。只有署名或只有祝福也能生成。

- “修改祝福或署名” → 花卡编辑浮层 → 更新花卡预览。
- “返回” → 作品预览。
- “分享” → 系统分享花卡图片菜单。
- “保存图片” → 手机相册，保存的是花卡图。

原作品图和花卡图分别维护导出状态、临时路径与错误；花卡生成不得覆盖原作品图片。修改花材或文字后旧图片失效，过期异步回调不得覆盖新图片。共享 Canvas 的绘制任务串行提交。

## 创作缓存

使用带版本号的本地草稿记录保存 Artwork、已提交祝福/署名和保存时间。Artwork 包含素材 ID/revision 及 containerLayouts，沿用并完善共享校验。只在用户实际编辑后保存，不因默认花瓶自动加载制造恢复提示。

- 编辑后短防抖写入；小程序隐藏和页面卸载时立即保存。
- 未提交花卡输入、选中状态、工具展开状态、原生图片临时路径、正在进行的导出任务不写入缓存。
- 从缓存恢复时保留合法花枝落点；修正当前 parseArtwork 将所有落点收拢到 338～362 的问题。容器素材准备完成后按实际瓶口校验，避免恢复后再次改变原布局。
- 恢复缺失版本素材时先尝试版本缓存，无法取得则显示可操作的素材错误，不静默替换花材或容器。
- 重新开始或结束创作只删除创作草稿，不删除下载过的花材/容器/背景资产。
- 清除流程取消防抖与旧异步恢复/导出回调，防止已清除的作品被迟到任务重新保存或显示。
- 存储读取/写入失败提示恢复或保存问题，不阻止当前创作；不得宣称保存成功。

## 我的作品（用户已确认补充）

全屏插花页增加“我的作品”入口，进入独立作品列表页。用户明确要求所有已保存作品存入云端，按登录账号隔离，换设备登录可读取和继续编辑；本地仅保留临时恢复草稿。保存作品和保存到相册是两个独立动作。

- 原作品预览增加“保存作品”：通过鉴权云对象保存可编辑 Artwork、已提交祝福/署名、名称、创建/更新时间、记录 revision，以及云存储缩略图。
- 默认名称使用“我的插花 + 日期时间”；保存前可改名，名称最多 40 字，空白使用默认名。
- 列表按最近保存时间倒序，两列缩略图，显示名称与时间；没有作品时提供“去插花”。
- 点击作品打开原作品预览，可保存图片、打开花卡编辑分享、继续编辑和删除。
- 继续编辑保存后的作品时采用编辑副本；未再次保存不会改写原作品。再次“保存作品”更新当前作品，同一创作连续保存不制造重复条目。
- 新作品会话和结束创作清除当前编辑作品 ID；保存作品不清临时草稿。
- 删除需确认，取消不删除；删除当前作品后返回列表，不连带清除其他作品或当前独立草稿。只清理该记录拥有且没有其他作品引用的缩略图，不触碰素材缓存。
- 重新开始、结束本次创作只清草稿，已保存作品保持完整。
- 读取失败、网络失败、缩略图上传或数据库写入失败明确报错，失败时保留旧作品。缩略图缺失时保留作品数据，打开后允许重新生成图片。
- 云对象 `_before` 复用公共 auth 校验身份，所有读取/更新/删除条件包含服务端 uid，不信任客户端 uid；数据库 schema 禁止客户端直接读写，并提供账号与更新时间索引。
- 保存新版本使用 expectedRevision 避免多设备同时更新相互覆盖；冲突提示重新读取，不静默覆盖。
- 缩略图由云对象根据已鉴权用户、作品 ID 和版本上传，禁止接受任意客户端文件引用；上传成功后写入数据库，数据库失败清理本次新文件，更新成功后清理旧文件。
- 服务端验证 Artwork、花卡文字、名称、缩略图大小与 PNG 格式；图片资源仅清理当前账号作品生成的文件。
- 作品列表返回工作室不重新初始化原创作。打开已保存作品、继续编辑前保存现有草稿；从作品详情返回列表时不覆盖原草稿。

## 保存与分享

原作品和花卡均支持点击放大、保存到手机相册和微信图片分享。用户取消保存或分享返回当前预览，不清缓存，不视为完成创作。平台不支持图片分享时提示先保存后分享。

相册权限被拒绝时给出打开设置的恢复动作；区分用户取消、拒绝权限和普通失败。所有平台调用只在用户点击对应按钮后进行。

## 代码职责

- 页面入口负责会话启动、恢复提示、视图切换与生命周期；不把缓存和目录加载放入叶子组件。
- artworkStore 继续负责作品编辑与历史。
- 新创作会话状态/草稿 hook 负责缓存、恢复、重置及花卡已提交数据。
- 图片 hook 保持原作品导出，补充花卡绘制/导出及对应保存分享，隔离两个图片结果。
- 原作品预览、恢复提示、花卡编辑和花卡预览分别拆成独立组件，使用现有主题、中文按钮和 rpx。
- 路由源通过 definePage 调整启动页；生成声明不手改。

## 验收

对图中每个分支编写有意义的状态及回调测试：

- 无缓存、继续恢复、重新开始、损坏缓存、存储失败、隐藏/卸载保存。
- 完成 → 原作品预览 → 返回编辑，作品不变。
- 原作品预览 → 分享 → 取消/跳过/全部留空/填写后预览。
- 花卡修改 → 取消/重新预览；返回原作品预览。
- 两种图片分别保存/分享；取消、不支持平台、拒绝相册权限、生成失败重试。
- 结束本次创作清缓存并回到空花瓶；迟到的导出和防抖不得复活旧作品。
- 容器布局、背景、落点及文字往返恢复正确。
- 我的作品保存/更新/排序/改名/打开/继续编辑/删除；草稿清除不影响收藏；服务端账号隔离、分页、跨设备读取、更新冲突与数据库/缩略图失败。

验证优先使用 node --test tests/*.test.cjs 和已安装 Vue 编译器；未获明确授权不运行 pnpm/corepack 的 lint、type-check、build 或安装命令。路由与构建变更需要构建验证，因此完整微信构建要在获得授权后执行。真实界面、真机相册/分享及安全区布局需另行实机验证，不能用离线测试代替。
